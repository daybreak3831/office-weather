⚙ 날씨 전광판 설정
사업장별 일반 설정, 사용자 알람, 기상경보 기준, 발생 로그와 버전 정보를 관리합니다.
📍 사업장 위치
사업장을 선택하면 해당 시설 좌표를 기준으로 현재 날씨와 예보가 제공됩니다.
사업장 정보를 불러오는 중입니다.
📹 현장 CCTV 등록
선택한 사업장에서 사용할 실시간 CCTV 스트림 주소를 직접 등록할 수 있습니다.
HLS(.m3u8) 형식의 직접 영상 주소를 권장합니다. 주소는 현재 브라우저의 해당 사업장 설정에만 저장됩니다.
설정은 각 TV/브라우저에 개별 저장됩니다. 같은 웹주소를 여러 사업장에서 사용해도 각 사업장의 설정은 서로 영향을 주지 않습니다.
🔔 사용자 시간 알람
점심·퇴근에 한정하지 않고 원하는 알람을 최대 10개까지 등록할 수 있습니다.

v4.4 후보
2026-10-07 · 창원시 공식 CCTV 143개 좌표와 등록 사업장 29곳의 최단 직선거리 대조 · 스트림 확인 완료 28곳 기본 CCTV 자동 등록 · 상복공원 최인접 CCTV는 재생목록 오류로 자동 등록 보류 · 기존 사용자 CCTV 설정 우선 적용 유지.
v4.3
사업장별 CCTV 스트림 주소 직접 등록 기능 추가 · 사용자 알람 입력창 안내 개선 · 설정 중 알람 테스트가 최상단에 표시되도록 수정 · 정보(패치노트) 탭 추가.
v4.2
설정을 일반/알람/로그 탭으로 분리하고, 최대 10개의 사용자 시간 알람과 기상경보 기준 사용자 설정, 알림 발생 로그 기능을 추가.
v4.1
폭염 및 호우 경보 기준 감지와 화면 경고 효과, 테스트 기능을 추가.
v4.0
창원특례시 구·사업장 선택 기능과 사업장별 위치 저장을 추가하여 여러 사업장에서 사용할 수 있는 범용 설정 구조로 확장.
v3.0
현장 도로 CCTV HLS 영상을 PIP 창에서 직접 재생하도록 구현하고 자동재생, 지연 감지, 자동 재연결, 60초 자동 종료를 적용.
v2.0
강풍·우천 자동 알림과 지속 시각 경고 효과, 기상상황 테스트 기능을 추가.
v1.8
페이지 실행 시 소리 자동 활성화를 시도하고 사용자 첫 조작으로 오디오가 자동 해제되도록 개선.
v1.7
알람 음원 캐시 문제를 줄이기 위한 버전 쿼리를 적용.
v1.6
GitHub Pages 파일 구조에 맞춘 알람 음원 경로 정리와 화면 버전 표시를 도입.
v1.x 초기
창원NC파크 사무실용 현재날씨·시간대별·주간예보 전광판과 기본 시간 알람 기능을 구축.
변경한 설정은 현재 TV/브라우저에 저장되며 다른 사업장의 설정에는 영향을 주지 않습니다.
